# 매뉴얼 변경 기록

## 2026-09-03

- 대표 전용 비공개 문서함을 추가했습니다. 설립 증빙·계약·산출물·정산 자료의 원본 위치를 버전으로 보관하며, 파일 업로드와 외부 공개는 포함하지 않습니다.
- 대표 전용 매출 원장을 추가했습니다. 고객사 프로젝트 청구와 앱·구독 매출을 한 목록에서 보고, 연결하지 못한 건은 미분류로 표시합니다. 결제 채널 자동 수집과 환불은 포함하지 않습니다.
- 대표 전용 AI 제안·확정 이력을 추가했습니다. 근거 기록에 연결된 현재 합의·다음 할 일·위험 초안만 등록하며, 대표 확정 전에는 공식 결정으로 보이지 않습니다. 자동 생성과 외부 실행은 포함하지 않습니다.
- 대표 전용 Recho 근거 타임라인을 추가했습니다. 메일·통화·회의의 원문 식별자·발생 시각·연결 이유를 프로젝트에 연결해 시간순으로 보여 주며, 원문은 복제하거나 수정하지 않습니다. Recho API 동기화와 AI 제안은 포함하지 않습니다.
- 대표 전용 고객사 담당자 등록을 추가했습니다. 고객사에 이름·역할·이메일·전화·관계 상태를 연결해 보관하며, Recho 기록 연결은 포함하지 않습니다.
- 대표 전용 업무·일정 기능을 추가했습니다. 프로젝트에 업무를 연결하고 기한과 완료 조건을 기록하며, 진행 중인 업무는 기한별로 보여 줍니다. 완료는 대표 확인 뒤에만 처리하고 Recho 캘린더 연동은 포함하지 않습니다.
- 대표 전용 분할 청구 일정을 추가했습니다. 체결된 계약에 착수금·중도금·잔금을 등록하고, 청구일·입금 예정일·입금 확인을 함께 보관합니다. 입금 확정은 대표 승인 뒤에만 처리하며 청구서 메일과 세금계산서 발행은 포함하지 않습니다.
- 대표 전용 날인 계약 보관 기능을 추가했습니다. 견적 버전을 계약 초안으로 옮기고, 날인 원본 위치를 기록한 뒤 대표 승인으로 체결합니다. 체결된 버전은 덮어쓰지 않으며, 전자서명 공급자는 연결하지 않습니다.
- 개발 PC 전용 `/setup/email`에서 Resend API 키만 로컬 비밀 설정에 저장하는 연결 경로를 추가했습니다. 기본 테스트 발신 주소와 실제 고객사 발신 도메인의 전환 기준을 운영 매뉴얼에 기록했습니다.
- 견적서 PDF 첨부 이메일 발송 기반을 추가했습니다. 대표 승인 체크, 발송 요청·실패 이력, 중복 요청 방지 키를 적용했으며, Resend API 키와 인증된 발신 메일이 없으면 외부 발송을 차단합니다.
- 대표 전용 화면에 대시보드·회사 설립 준비·고객사·프로젝트·견적서로 이동하는 공통 좌측 내비게이션을 추가했습니다.
- 대표 전용 견적서 초안·수정 이력 기능을 추가했습니다. 견적은 고객사에 연결하고, 항목별 공급가액·부가세 별도(10%)·합계를 보관합니다. 수정은 새 버전으로만 저장되며 각 버전은 실제 PDF 파일을 내려받거나 인쇄할 수 있습니다.
- 프로젝트 목록에서 상태와 진행률을 수정하고 변경 이력을 남기는 기능을 추가했습니다.
- 대표 전용 고객사·프로젝트 등록 화면을 추가했습니다. 고객사에 프로젝트를 연결하고 상태와 진행률을 함께 관리합니다.
- 대표 전용 회사 설립 준비 화면을 추가했습니다. 개인사업자 등록 준비 항목별 상태·증빙 위치·확인 메모를 저장하고, 기본 항목 생성과 변경을 감사 이력에 남깁니다.
- 개발용 데이터베이스 연결 문자열을 로그인 설정과 분리해 로컬 전용으로 추가하는 경로를 만들었습니다. 이 경로는 기존 설정을 덮어쓰지 않고 `ai-development`만 대상으로 합니다.
- 개발 PC용 최초 연결 화면 `/setup`을 추가했습니다. 입력값은 새 `.env.local`에만 저장하며, 기존 파일과 운영 배포는 보호합니다.
- Coreloom의 첫 운영 매뉴얼을 만들었습니다.
- 미래 배포본의 관리자 전용 `/admin/manual`에서 저장소 `manual/` 원본을 읽기 전용으로 보여 주는 계약을 추가했습니다.
- 1인 창업자와 AI 에이전트 팀 운영 모델을 반영했습니다. AI 에이전트는 업무 초안과 요청까지만 수행하며, 금전·권한·계약·외부 공개의 최종 결정은 대표가 승인합니다.
- 회사 설립 준비, 고객사 견적·계약·분할 청구, Recho 근거 타임라인, 앱·구독 매출, 전자세금계산서 활성화 조건을 반영했습니다.
- 전용 Neon Free 프로젝트를 싱가포르 리전에 만들고, 운영 데이터 경계인 `production`과 AI 개발 전용 `ai-development` 브랜치를 분리했습니다. 운영 브랜치에는 AI MCP와 실험용 AI 도구를 연결하지 않습니다.
- 대표 전용 Neon Auth 로그인 화면과 서버 측 대표 이메일 검사 기반을 추가했습니다. 공개 가입은 사용하지 않으며, 최초 대표 계정과 비밀 환경값은 Console·로컬 환경에서만 관리합니다.
- 워크스페이스·구성원·감사 이력의 첫 Neon SQL 마이그레이션과 개발 브랜치 전용 적용 가드를 만들었습니다.
- 수동 운영 백업과 브랜치 승격 절차를 `docs/operations/neon-branch-and-backup-runbook.md`에 추가했습니다.
- 대표 전용 비밀번호 설정·재설정 화면을 추가했습니다. 요청 결과는 계정 존재 여부를 드러내지 않으며, 비밀번호는 대표가 메일 링크에서 직접 설정합니다.
