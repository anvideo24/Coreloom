## 완료 기준과 확인 상태

자동 시험은 실제 구성 요소와 가상 자료로 확인한다. 실제 DB 저장·실기기 사용 시험으로 표시하지 않는다.

| ID | 완료 기준 | 상태 |
| --- | --- | --- |

| OR-02 | 두 폼 모두 저장 중 추가 요청 0건, 저장 중임을 표시 | ☑ 자동 시험 2/2 · 요청 횟수·비활성·라벨·aria-busy |
