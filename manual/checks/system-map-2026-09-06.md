- SM-03: 네 폭 모두 `documentElement.scrollWidth - clientWidth = 0`. 4K에서 메뉴 접힘 시 구조도 폭 3696px, 메뉴 펼침 시 3520px. 설명 본문만 66ch로 제한한다.

- SM-05: 버튼 20/20이 48px 이상, 제목·라벨 잘림 0. 4K 제목의 scrollHeight 50px / clientHeight 48px는 overflow visible의 글꼴 영역 차이였다. 이를 잘림으로 세지 않았으며 스크린샷에서 온전한 제목을 확인했다.
- 마지막 일괄 재측정 중 브라우저 제어가 끊겼다. 반환되지 않은 측정은 증거에 포함하지 않았다. 앞서 완료한 개별 측정만 위에 기록했다. 임시 화면 폭 설정 해제와 최종 재진입은 미확인이다.
