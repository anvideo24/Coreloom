## 승인안 대비 남은 것

- 미저장 경고는 버리기 또는 계속 편집이다. 경고창 안에서 바로 저장하는 세 번째 선택은 남아 있다.
- 서버 폴더 선택기와 매뉴얼 렌더러 개편은 이번 묶음 밖이다. 기존 경로 입력과 서버 권한 검사는 유지한다.
- main 병합·배포는 하지 않았다. 검사는 작업 가지와 개발 PC 화면 기준이다.
