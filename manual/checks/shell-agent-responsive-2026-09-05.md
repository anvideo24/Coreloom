## 승인안 대비 남은 것

- 미저장 경고는 버리기 또는 계속 편집이다. 경고창 안에서 바로 저장하는 세 번째 선택은 남아 있다.
- 서버 폴더 선택기와 매뉴얼 렌더러 개편은 이번 묶음 밖이다. 기존 경로 입력과 서버 권한 검사는 유지한다.
- main 병합·배포는 하지 않았다. 검사는 작업 가지와 개발 PC 화면 기준이다.

## 재현

### 후속 적용 기록

- 공통 셸은 PR #104, `614d2a4`로 main 병합. GitHub 타입·시험·빌드 및 병합 후 main CI 통과.
- 이후 `codex/agent-settings-save-guard`에서 미저장 설정의 3선택을 구현했다. 대화·자료 접근 저장, 실패·권한 확인 취소, 일부만 저장된 뒤 재시도, 같은 순간 중복 저장, 에이전트 변경 취소, 닫힌 패널 밖 경고 DOM을 자동 검사한다. 전체 62개 시험 파일·415개 시험과 타입 검사 통과.
- 실제 PC에서는 720×500의 대화 패널 가로 넘침 0, 입력 도구 높이 48px와 화면 안 배치를 확인했다. 1440×1000 화면의 200% 확대에 대응하는 CSS 작업 공간 점검일 뿐 실제 브라우저 확대 검증은 아니다.
- 같은 크기에서 3선택 경고가 보였고 Escape는 경고만 닫으며 미저장 문구와 AI 패널을 유지했다. 실제 DB 저장·권한 변경은 하지 않았다.
- 닫힌 AI 패널에서 다른 페이지로 갈 때 기존 경고가 0×0 크기로 숨는 실패를 실측했다. 이를 문서 본문 포털로 수정하고 자동 검사했다. 이후 브라우저 제어가 중단돼 최종 포털의 실제 화면 재검증은 미완료다.
- 매뉴얼 입구·대화 패널의 표시 텍스트 72개를 점검해 작은 주황 제목 1개가 3.48:1임을 확인했다. 글자용 색 토큰으로 고친 뒤 같은 캔버스 대비 계산은 5.19:1이며 회귀시험 통과. 전 제품 색 대비 검증은 아니다.
- 실제 Fold 키보드, 실제 브라우저 200% 확대와 최종 경고 화면 재검증이 남는다. 후속 변경의 main 병합·배포는 아직이다.

- 후속 IAB 실사용 확인: `/admin/manual` AI 설정에서 일회성 미저장 문구를 입력한 뒤 패널을 닫고 공용 규칙 링크를 선택했다. 닫힌 패널 밖 문서 본문에 native guard가 표시됐고, innerWidth 342·height 798에서 clientWidth 331, scroll overflow 0px를 확인했다. 대화상자는 292.76×324.30px, x=19·y=236.82로 전체 화면 안에 있었고 세 선택지 버튼 높이는 약 48px이었다.
- 같은 세션에서 Escape는 guard만 닫았다. AI 패널을 다시 열었을 때 미저장 초안이 유지됐고, 다시 패널을 닫고 링크를 눌러 `버리고 계속`을 선택하면 `/admin/manual/shared/rules`로 실제 이동했다. 시험 문구와 guard는 남지 않았다. IAB viewport는 확인 후 원복했다. 실제 설정·권한은 저장하지 않았다. 실제 Fold 키보드와 실제 브라우저 200% 확대는 여전히 미검증이며 후속 PR #105는 main 반영 전이다.
