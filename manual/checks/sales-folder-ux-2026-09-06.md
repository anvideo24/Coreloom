# 고객사·견적 입력과 서버 PC 폴더 선택 확인

## 이번 묶음

대표가 승인한 두 작업을 병렬로 구현한다. 고객사·견적의 목록/생성 화면과 에이전트 설정만 변경한다. DB 스키마·계산·외부 발송·전체 PC 접근은 변경하지 않는다.

## 목표와 체크리스트

| 확인 항목 | 목표 | 현재 증거 |
| --- | --- | --- |
| 새 작업 버튼 | 고객사·견적 2곳 모두 행동 문구 표시 | 확인: 실제 로그인 화면 2곳 |
| 목록 검색 | 고객사 이름, 견적 주제·고객사로 좁히고 빈 결과 표시 | 자동 통과: sales-ux 시험. 실제 목록은 비어 있어 실데이터 검색 미검증 |
| 생성 첫 입력 | 상호·거래 유형 2개 우선, 나머지 선택 정보 접힘 | 확인: 실제 고객사 생성 2개 필드·접힌 3개 그룹 |
| 접힌 정보 보존 | 원래 필드가 FormData와 초안에서 빠지지 않음 | 자동 통과: 폼/초안 시험. 실제 미전송 상호 닫기·재열기 복원 1회, 확인용 초안 제거 |
| 새 견적 편집 | 첫 탭에서 품목 편집, 미리보기는 명시적으로 전환 | 자동 통과: 기본 편집 탭·기존 견적 동선 시험. 실제 품목 입력은 고객사 미등록으로 미검증 |
| 폴더 탐색 | 파일 내용 없이 서버 PC의 직속 하위 폴더 선택 | 확인: 대표 로그인 후 시작 위치·드라이브·하위 폴더 탐색, 선택 목록 1개 표시 |
| 권한 경계 | 탐색·선택만으로 저장/AI 권한 변경 0회 | 자동 통과: 권한·설정 시험. PC에서는 추가→제거→버리고 이동, 저장 0회 |
| 폴더 제한 | 중복·8개 초과·보호 경로·링크 차단 | 자동 통과: picker·공유 파일 경계 시험. PC 드라이브 전체 추가 비활성 확인. 탐색 열거 시험은 파일 경계 함수를 mock함 |
| 응답 경합 | 저장 중 추가 불가, 취소/이전 에이전트 응답 무시 | 자동 통과: picker 경합·재시도·에이전트 전환 시험 |
| 반응형 | 접힌/펼친 폴드·데스크톱 폭에서 페이지 넘침 0 | 부분 확인: 고객사 342·724·1305px, 폴더 설정 342·724·1440px, 견적 342·3151px 넘침 0. 실물 Fold·3840px·키보드 미검증 |

## 검증 범위

검사 통과와 main 병합, PC 화면 반영은 별도로 기록한다. 사람의 탐색 시간·인지 부하 감소는 이 변경만으로 통과 처리하지 않는다. 실제 회사 자료나 권한은 테스트 목적으로 저장하지 않는다.

## 검사 결과 · 2026-09-06

- 전체 시험 440개와 타입 검사 통과. 배포용 빌드 통과(동적 파일 추적 경고 9건).
- 신규 폴더 구현·시험의 지정 파일 lint 통과. 저장소 전체 lint는 기존 파일들을 포함한 오류로 실패했으며 통과로 취급하지 않는다. 발견한 신규 picker effect 오류는 키 기반 상태 초기화로 수정하고 관련 22개 시험을 재확인했다.
- 작업 가지 `codex/client-quote-folder-ux`에서 PC 화면 확인. main 병합·외부 CI 통과는 아직 이 기록에 포함하지 않는다.
- 확인용 상호 초안과 폴더 선택은 제거했다. DB 스키마·고객사·견적·접근 권한을 저장하지 않았다.
