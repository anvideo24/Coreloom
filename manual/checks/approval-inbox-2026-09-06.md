# 승인함 탐색·검토 UX 확인

## 목표와 범위

대상을 찾고 검토에 필요한 정보를 구별하기 쉽게 한다. 빠른 승인 자체가 목표는 아니다. 검색·종류 필터와 읽기 전용 목록만 개선하며 실제 승인·반려·데이터 조회 범위·기존 목록 순서는 유지한다.

이번 기준은 기존 [F03 계획](../../docs/superpowers/plans/2026-09-05-measurable-improvements.md)의 보조 검사다. F03-01의 5회 탐색 중앙값 15초 이내·오선택 0건, F03-02의 5사례 오판 0건은 사람이 나중에 측정한다. 자동 시험을 그 결과로 대신하지 않는다.

## 검증 기록

작업 가지: `codex/approval-inbox-clarity`. 테스트는 가상 목록과 실제 화면 컴포넌트를 사용하며 실제 DB·승인·반려·발송을 실행하지 않는다. 외부 CI·main 병합은 별도다.

수정 전 새 화면 시험 3개에서 검색·표시 건수·날짜 및 안내 부재를 확인했다. 수정 후 집중 시험 3개, 전체 **73파일 488개 시험**, TypeScript·diff 공백 검사 통과. 검색 대상은 목록에 표시된 제목·설명·종류이며 실제 원문 파일이나 증빙을 조회하지 않는다.

통합 코드 검토에서 모바일 금액·날짜·링크의 한 줄 몰림을 줄바꿈 가능한 배치로 보완하고, 키보드 초점 대비와 긴 한글·금액 줄바꿈을 명시했다. 이는 코드 보완이며 AP-07의 실화면 통과를 의미하지 않는다. 인증·조회 데이터·확정 절차·DB·서버 설정은 변경하지 않았고 개발 서버 재기동·로컬 빌드·브라우저 시험도 하지 않았다.
