## 재현 가능한 가상 함수 시험

apps/web에서 기존 tsx 의존성으로 아래 TypeScript를 실행한다. DB 연결·환경변수 조회·파일 저장·네트워크 호출은 없다. PowerShell에서는 코드 문자열을 변수에 담아 `node node_modules/tsx/dist/cli.mjs -e $auditFixture`로 전달한다.

```typescript
import { buildFounderDashboard, monthWeekBuckets } from './src/lib/domain/dashboard.ts';
const base = {
  today: '2026-09-05', setupItems: [], quotes: [], contracts: [], billings: [],
  pendingProposals: [], projects: [],
  revenue: { confirmedAmount: 0, scheduledAmount: 0, unclassifiedCount: 0 },
  expenses: [], tasks: [], recentDecisions: [], documentCount: 0,
};
const billing = {
  id: 'b-test', clientName: 'SYNTHETIC', contractTitle: 'TEST', kindLabel: '잔금',
  amount: 100, billingDate: '2026-09-29', dueDate: '2026-09-30', status: 'scheduled',
};
const end = buildFounderDashboard({ ...base, billings: [billing] });
const cross = buildFounderDashboard({
  ...base,
  projects: [
    { id: 'p1', name: 'TEST-P1', clientName: 'SYNTHETIC', status: 'active', progressPercent: 0 },
    { id: 'p2', name: 'TEST-P2', clientName: 'SYNTHETIC', status: 'active', progressPercent: 0 },
  ],
  quotes: [{ quoteId: 'q1', versionId: 'v1', versionNumber: 1, title: 'TEST-Q1', clientName: 'SYNTHETIC', totalAmount: 100, emailRequested: false }],
});
const timing = buildFounderDashboard({ ...base, billings: [{ ...billing, billingDate: '2026-09-02', dueDate: '2026-10-02' }] });
console.log({
  coveredThrough: monthWeekBuckets(base.today).at(-1)?.end,
  monthEndInput: 100,
  monthEndDisplayed: end.cashWeeks.reduce((s, w) => s + w.inflow, 0),
  bothProjectsMarkedQuoted: cross.projectCards.map(p => p.stages.quote),
  octoberDueCountedInSeptember: timing.cashWeeks.reduce((s, w) => s + w.inflow, 0),
});
```

측정 당시 결과: coveredThrough=2026-09-28, monthEndInput=100, monthEndDisplayed=0, bothProjectsMarkedQuoted=[true,true], octoberDueCountedInSeptember=100.

위 결과는 버그 수정 후 기대값이 아니다. 수정 전 관찰값을 보존한 것이다. 전체 회계 정확도·실사용 데이터 오류 또는 사용자의 판단 시간을 입증하지 않는다.
