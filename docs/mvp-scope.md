# Coreloom MVP 범위

## 목표

1인 창업자가 한 곳에서 **어떤 사업이 진행 중인지**, **AI 에이전트가 무엇을 하고 있는지**, **이번 달 돈이 어디서 들어오고 나가는지**를 확인하고 필요한 승인을 남긴다.

이 문서는 강의·앱·온라인 서비스를 함께 운영하는 1인 기업의 첫 기준이다. 첫 출시 목표는 회계 프로그램을 대체하는 것이 아니라, 사업별 운영 정보를 한 화면에서 연결하는 것이다.

## 사용자와 권한

| 역할 | 할 수 있는 일 |
| --- | --- |
| 대표 | 전체 현황 조회, 사업·거래처 관리, 최종 승인, 권한 관리 |
| AI 에이전트 | 허용된 프로젝트 업무 업데이트, 조사·초안 작성, 지출·공개 요청 초안 |
| 외부 협업자 | 맡은 프로젝트의 업무 업데이트와 자료 첨부 |

## MVP에 포함할 기능

### 1. 대시보드

- 이번 달 예정 매출, 확정 비용, 예상 잔액
- 사업별 손익, 진행 중 프로젝트, 마감 임박 업무, 대기 중 승인
- 현금흐름 경고: 예산 초과 또는 입금 예정일 경과

### 2. 회사 기본 정보

- 사업: 강의·앱·온라인 서비스처럼 독립 수익·비용 흐름을 가진 운영 단위
- 구성원: 이름, 소속, 역할, 입사일, 연락처
- AI 에이전트: 이름, 목적, 허용 업무, 접근 범위, 상태
- 거래처: 회사명, 담당자, 연락처, 계약/정산 메모
- 프로젝트: 담당자, 기간, 상태, 예산, 연결 거래처

### 3. 업무와 승인

- 프로젝트별 업무 등록·담당자 또는 에이전트·마감일·상태 관리
- 지출 요청: 금액, 용도, 증빙 파일, 연결 프로젝트
- 대표 승인 또는 반려와 이력 보존
- 에이전트 작업: 요청자, 실행 에이전트, 결과물, 사람 승인 여부 기록

### 4. 매출·비용 관리

- 매출 예정/확정 기록: 거래처, 금액, 입금 예정일·실제일, 사업 연결
- 비용 기록: 카테고리, 금액, 결제일, 증빙, 사업·프로젝트 연결
- 월별 매출·비용·예상 잔액 요약과 CSV 내보내기

### 5. 기록과 안전장치

- 변경·승인·반려 시각과 실행자 기록
- 역할별 접근 제어
- 파일은 원본을 유지하고 삭제는 관리자만 가능

## MVP에서 제외할 것

- 급여 계산, 4대보험, 원천세, 전자세금계산서 발행
- 은행 계좌 자동 조회·이체·법인카드 자동 수집
- 재고·생산·구매·물류 관리
- 외부 고객용 포털과 견적서/계약서 전자서명
- 고급 BI, AI 예측, 모바일 앱

이 항목들은 운영 방식과 연동 대상이 확정된 뒤 2차 범위로 검토한다.

## 첫 화면 구성

1. 오늘 확인할 것: 승인 대기, 마감, 입금 지연
2. 회사 현황: 사업별 매출·비용·예상 잔액
3. 프로젝트: 진행률과 예산 사용 현황
4. 최근 기록: 업무·비용·승인·에이전트 작업 이력

## 완료 기준

대표가 아래 흐름을 실제로 끝낼 수 있으면 MVP의 첫 버전으로 본다.

1. 사업·구성원·AI 에이전트·거래처·프로젝트를 등록한다.
2. AI 에이전트 또는 협업자가 프로젝트 업무와 지출·공개 요청을 올린다.
3. 대표가 승인 또는 반려한다.
4. 대표가 매출·비용을 사업별로 기록하고 월별 현금흐름을 확인한다.
5. 대표가 변경 이력과 에이전트 작업 이력을 확인하고 CSV로 내려받는다.

## 확정이 필요한 사업 결정

- 외부 협업자 합류 시의 역할과 데이터 접근 범위
- 인원이 늘었을 때의 금액별 승인자와 승인 단계
- 회계 프로그램 또는 은행·카드 연동 필요 여부
- 웹 우선인지, 현장용 모바일 우선인지
