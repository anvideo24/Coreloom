# Coreloom MVP 범위

## 목표

Coreloom은 1인 개인사업자가 회사 설립 준비부터 고객사 프로젝트의 견적·계약·분할 청구·입금, 앱·구독 서비스 매출·비용, 프로젝트 진행까지 한곳에서 관리하는 비공개 운영 OS다.

상세 설계와 활성화 조건은 [운영 OS 설계](superpowers/specs/2026-09-03-coreloom-operating-os-design.md)를 따른다.

## 첫 구현에 포함할 것

1. 회사 설립 준비 체크리스트와 증빙이 필요한 비공개 문서함
2. 고객사·담당자·프로젝트 등록과 Recho 기록 연결
3. 수정 이력이 있는 견적서, PDF 생성, 대표 승인 후 이메일 발송
4. 전자서명 계약 또는 날인한 계약 원본의 보관과 상태 관리
5. 업무·캘린더·진행률·분할 청구·입금 상태
6. Recho의 시간순 근거, AI 제안, 대표 확정·반려 이력
7. 고객사 프로젝트와 앱·구독을 함께 보는 매출·비용 원장

## 자격과 공급자 준비 후 활성화할 것

- 팝빌 전자세금계산서 실발행과 결과 상태 수신
- 전자서명 공급자 연동
- 앱·구독 결제 채널의 자동 매출 수집

## 제외할 것

- 급여, 4대보험, 원천세, 재고, 구매·물류
- 대표 승인 없는 자동 결제·이체·계약 체결·외부 발송·세금계산서 발행

## 완료 기준

대표가 회사 설립 준비 증빙을 확인하고, 고객사 프로젝트를 견적부터 계약·진행·분할 청구·입금까지 처리하며, 관련 메일·통화·회의의 근거와 AI 제안을 보고 직접 확정할 수 있다.
