# Coreloom MVP 범위

## 목표

법인 운영자가 한 곳에서 **누가 어떤 일을 하고 있는지**, **어떤 거래가 진행 중인지**, **이번 달 돈이 어디서 들어오고 나가는지**를 확인하고 필요한 승인을 남긴다.

이 문서는 업종 미확정 상태에서 만드는 공통 운영 ERP의 첫 기준이다. 첫 출시 목표는 회계 프로그램을 대체하는 것이 아니라, 운영 정보를 한 화면에서 연결하는 것이다.

## 사용자와 권한

| 역할 | 할 수 있는 일 |
| --- | --- |
| 대표/관리자 | 전체 현황 조회, 구성원·거래처 관리, 승인, 권한 관리 |
| 팀원 | 맡은 프로젝트·업무 업데이트, 지출 요청, 자료 첨부 |
| 회계 담당자 | 매출·비용 기록 검토, 월별 현금흐름 확인, 내보내기 |

## MVP에 포함할 기능

### 1. 대시보드

- 이번 달 예정 매출, 확정 비용, 예상 잔액
- 진행 중 프로젝트, 마감 임박 업무, 대기 중 승인
- 현금흐름 경고: 예산 초과 또는 입금 예정일 경과

### 2. 회사 기본 정보

- 구성원: 이름, 소속, 역할, 입사일, 연락처
- 거래처: 회사명, 담당자, 연락처, 계약/정산 메모
- 프로젝트: 담당자, 기간, 상태, 예산, 연결 거래처

### 3. 업무와 승인

- 프로젝트별 업무 등록·담당자·마감일·상태 관리
- 지출 요청: 금액, 용도, 증빙 파일, 연결 프로젝트
- 관리자 승인 또는 반려와 이력 보존

### 4. 매출·비용 관리

- 매출 예정/확정 기록: 거래처, 금액, 입금 예정일·실제일
- 비용 기록: 카테고리, 금액, 결제일, 증빙, 프로젝트 연결
- 월별 매출·비용·예상 잔액 요약과 CSV 내보내기

### 5. 기록과 안전장치

- 변경·승인·반려 시각과 실행자 기록
- 역할별 접근 제어
- 파일은 원본을 유지하고 삭제는 관리자만 가능

## MVP에서 제외할 것

- 급여 계산, 4대보험, 원천세, 전자세금계산서 발행
- 은행 계좌 자동 조회·이체·법인카드 자동 수집
- 재고·생산·구매·물류 관리
- 외부 고객용 포털과 견적서/계약서 전자서명
- 고급 BI, AI 예측, 모바일 앱

이 항목들은 운영 방식과 연동 대상이 확정된 뒤 2차 범위로 검토한다.

## 첫 화면 구성

1. 오늘 확인할 것: 승인 대기, 마감, 입금 지연
2. 회사 현황: 이번 달 매출·비용·예상 잔액
3. 프로젝트: 진행률과 예산 사용 현황
4. 최근 기록: 업무·비용·승인 변경 이력

## 완료 기준

관리자가 아래 흐름을 실제로 끝낼 수 있으면 MVP의 첫 버전으로 본다.

1. 구성원·거래처·프로젝트를 등록한다.
2. 팀원이 프로젝트 업무와 지출 요청을 올린다.
3. 관리자가 승인 또는 반려한다.
4. 회계 담당자가 매출·비용을 기록하고 월별 현금흐름을 확인한다.
5. 관리자가 변경 이력을 확인하고 CSV로 내려받는다.

## 확정이 필요한 사업 결정

- 첫 사용 회사의 업종과 인원 수
- 비용 승인 기준: 금액별 승인자와 승인 단계
- 회계 프로그램 또는 은행·카드 연동 필요 여부
- 웹 우선인지, 현장용 모바일 우선인지
