# 운영 화면 리스트·작성 패널 롤아웃과 필드 격차

> 고객사(`/clients`)에서 쓴 방식(리스트 먼저 · 헤더 `+` · 구역·2열 작성 패널 · 실무에 필요한 필드)을 다른 운영 화면에 같은 **껍데기**로 맞추기 위한 정본이다.
> UX 껍데기는 견적·에이전트·고객사에서 검증된 것을 가져오고, **필드 세트는 면마다 역할로 다시 고른다.**

상태 기준:
- **완료**: 리스트+패널 + 추천 필드가 이 가지(또는 `main`)에 있음
- **다음**: 바로 구현할 순서
- **보류**: MVP 밖이거나 자격·공급자 대기

---

## 공통 UX (이미 정한 것)

| 항목 | 선택 |
|---|---|
| 첫 화면 | 리스트 |
| 생성 | 헤더 `+` → `CreatePanel` (`?new=1`) |
| 이중 생성 | 청구·매출처럼 종류가 둘이면 `+` 둘(`?new=1` / `?new=series`·`venture`) |
| 폼 레이아웃 | 구역 라벨 + 짧은 칸 2열 · 긴 칸 한 줄 (견적 `quote-form`) |
| 스크롤바 | 작성 패널 얇은 pill, `--line`/`--muted` 톤 |
| 가져오지 않음 | 견적 INVOICE·원가 xlarge 레이아웃 |

## 고객사에 아직 없는 것 (요약)

과세 유형·고객 계좌·거래 유형은 넣었다. 사업자등록증 실파일은 문서함에서 고객사에 연결해 올린다. 남은 후보는 담당자 부서 분리 등이며 MVP에 필수는 아니다.
